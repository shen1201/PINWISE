# PINWISE｜投資情報與智慧選股 AI Agent

> 不替你決定買哪一檔，而是讓每個數字看得懂、查得到、算得出來。

PINWISE 是為投資新手設計的台股研究 AI Agent。名字由 **PIN**（把值得關注的標的「釘」出來）與 **WISE**（智慧）組成，意思是「用智慧選擇標的」。每一個被選出來的標的，都附上理由、風險與資料來源。

NAPAI Agentic AI 校園落地創新應用競賽 2026｜B 組・題目一 決賽作品。

> ⚠️ AI 投資研究輔助，不是自動下單或保證獲利工具。行情為最近可得的日資料，不是即時行情。

## 為什麼做 PINWISE

我們收集了 28 份投資新手問卷：

- 15 / 28 位新手靠社群媒體找投資資訊，來源難以追溯。
- Kano 分析中，新手最想要的是 **推薦理由解釋** 與 **風險監控／異常提醒**（加分度皆 0.68），單純的「AI 選股建議」反而排在後面（0.44）。
- 換用新工具時最大的阻力是「習慣現有操作」與「不確定新工具」，所以新工具必須讓人看得出為什麼可信。

因此 PINWISE 的原則是：**每個推薦都附理由與風險、每個數字都有白話解釋、每個結論都查得到來源與日期。**

## Agent 設計：AI 負責理解與解說，程式負責資料與計算

```
理解需求 → 規劃步驟 → 呼叫官方資料 → 程式計算 → 逐句檢核 → 白話解說
 (Gemini)    (程式)       (程式)        (程式)      (程式)     (Gemini)
```

| 步驟 | 做什麼 |
| --- | --- |
| 理解需求 | 把一句白話拆成篩選條件 |
| 規劃步驟 | 決定要查哪些資料與工具；查不到就放寬條件或改走備援 |
| 呼叫官方資料 | 只使用白名單工具（證交所、櫃買中心、公開資訊觀測站、FinMind） |
| 程式計算 | 期間報酬、年化波動、最大回撤等由 Python 計算，數字不交給模型 |
| 逐句檢核 | 依標的、數值、單位、日期與來源逐句核對，沒有證據的句子會被移除 |
| 白話解說 | 附上理由、風險與資料來源 |

- **狀態與記憶**：每一步留下紀錄並即時顯示；助手記得上一題，可以接續追問。
- **人在關鍵點決定**：研究前先確認，執行中可暫停或取消；不給買賣指令，最後由使用者判斷。

## 功能

| 功能 | 說明 |
| --- | --- |
| **智慧選股** ⭐ | 一句話篩選全市場，每檔附理由與走勢 |
| **AI 標的研究** ⭐ | 先確認再執行，產出研究報告、風險與失效條件 |
| **PINWISE 助手** ⭐ | 白話問答，數字核對過才顯示 |
| 追蹤與通知 | 新公告與大漲大跌主動提醒 |
| 股票比較 | 同一標準並排比較；ETF 可看成份股重疊 |
| ESG 專區 | 公司自行申報的 9 個揭露主題 |
| 我的投資足跡 | 研究歷程、回饋與目標試算 |
| 學習專區 | 名詞查找、常見問題、新手導覽 |
| 資料與證據中心 | 每個資料來源的狀態、更新日期與授權 |

⭐ 為核心 Agent 功能。

## 技術架構

| 層 | 技術 |
| --- | --- |
| 前端 | Vue 3 + Vite |
| 後端 | Python 3.11 + FastAPI |
| AI 模型 | Google Gemini（只負責理解問題與白話整理） |
| 資料來源 | TWSE、TPEx、MOPS 公開資料、FinMind、各投信官網 ETF 成份股 |
| 儲存 | PostgreSQL（選用；未設定時存為本機 JSON） |
| 對外展示 | ngrok 固定網址，後端同時提供 API 與打包好的前端 |

所有 API 金鑰只放在後端，不會進到瀏覽器。

## 本機執行

需要 Python 3.11+、Node.js 18+ 與 Gemini API Key。完整步驟、環境變數與測試方式請看 **[FinPilot-AI-V7.0-R2-Mac/README.md](FinPilot-AI-V7.0-R2-Mac/README.md)**。

```powershell
cd FinPilot-AI-V7.0-R2-Mac
python -m venv .venv
.venv\Scripts\python -m pip install -r backend/requirements.lock
# 建立 .env，至少填入 GEMINI_API_KEY（範例見 backend/.env.example）
.venv\Scripts\python -m backend.run

# 另開一個終端機
cd frontend-vue
npm install
npm run dev        # 開啟 http://localhost:5173
```
